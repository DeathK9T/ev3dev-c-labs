# Лабораторная №7. Многопоточность и датчик цвета

## Что такое поток (task)?

**Поток** - это независимая последовательность инструкций, которая может выполняться параллельно с другими потоками.

## Концепция многопоточности

В сложных робототехнических системах необходимо одновременно выполнять несколько задач:

- Читать данные с датчиков
- Управлять двигателями
- Выводить информацию на экран
- Обрабатывать пользовательский ввод

Многопоточность позволяет разделить эти задачи на независимые потоки выполнения.

## Преимущества многопоточности в робототехнике

1. **Разделение ответственности** - разные потоки выполняют разные функции
2. **Быстрая реакция** - датчики читаются независимо от основной логики
3. **Стабильная частота** - каждый поток может работать со своей частотой
4. **Масштабируемость** - легко добавлять новые функции

## Синтаксис потоков в EV3 C

### Объявление потока

```c
task sensorReader() {
    while(true) {
        // код потока
        delay(50);
    }
}
```

### Запуск потока

```c
task main() {
    startTask(sensorReader); // запуск потока
    // основной код
}
```

### Обмен данными между потоками

Потоки обмениваются данными через **глобальные переменные**:

```c
// Глобальные переменные (объявляются вне всех функций)
float leftSensor = 0.0;
float rightSensor = 0.0;
bool sysActive = true;

task sensorReader() {
    while (sysActive) {
        leftSensor = getColorReflected(S1);
        rightSensor = getColorReflected(S3);
        delay(20);  // Частота чтения 50 Гц
    }
}

task showInfo() {
    while (sysActive) {
        displayTextLine(1, "Left: %.2f", leftSensor);
        displayTextLine(2, "Right: %.2f", rightSensor);
        delay(200);  // Обновление экрана 5 раз в секунду
    }
}

task main() {
    startTask(sensorReader);
    startTask(showInfo);

    // Основной поток управления
    while (true) {
        setMotorSpeed(motorD, 40);
        setMotorSpeed(motorA, 40);

        delay(50);

        if (getButtonPress(buttonEnter)) {
            sysActive = false;
            break;
        }
    }
}
```

#### Принципы безопасного обмена

- Используйте простые типы данных (int, float, bool)
- Избегайте одновременной записи в одну переменную из разных потоков
- Читающие потоки должны быть готовы к изменению данных

## Архитектура многопоточной системы

### Типичная структура

- **Поток чтения датчиков** - непрерывное обновление данных датчиков
- **Поток управления движением** - основная логика навигации
- **Поток пользовательского интерфейса** - обновление экрана, обработка кнопок
- **Главный поток** - координация работы системы

## Датчик цвета EV3

Датчик цвета может работать в нескольких режимах:

- **Режим отражения (reflected)** — измеряет яркость отраженного красного света - **getColorReflected()**
- **Режим цвета** — определяет цвет поверхности - **getColorRGB(), getColorRed(), getColorGreen(), getColorBlue()**
- **Режим внешнего освещения** — измеряет окружающий свет - **getColorAmbient()**

- Ожидание нажатия центральной кнопки для начала работы алгоритма в нужное время *(getButtonPress(buttonEnter))*

- Робот старается вытолкнуть другого(их) робота(ов) за пределы поля
