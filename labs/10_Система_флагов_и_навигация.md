# Лабораторная №10. Система флагов и навигация

## События в системах реального времени

В робототехнике событие - это значимое изменение состояния системы или окружающей
среды, требующее немедленной реакции.

### Типы событий

- Сенсорные - изменение показаний датчиков
- Временные - истечение таймера
- Пользовательские - нажатие кнопки
- Системные - завершение движения, ошибка

### Проблема опроса (polling)

Постоянная проверка условий в главном цикле приводит к:

- Задержкам в реакции
- Пропуску коротких событий
- Неэффективному использованию ресурсов

## Система флагов

**Флаг** - это булева переменная, сигнализирующая о наступлении события.

```c
// Глобальные флаги событий
bool lineDetected = false;
bool crossroadDetected = false;
bool obstacleDetected = false;
bool emergencyStop = false;
```

### Принципы работы с флагами

1. Установка флага происходит в потоке-детекторе
2. Проверка флага происходит в основной логике
3. Сброс флага происходит после обработки события

## Распознавание пересечений

### Анализ суммы датчиков

- Нормальное следование: сумма ≈ 1.0 (один на черном, один на белом)
- Потеря линии: сумма > 1.7 (оба на белом)
- Пересечение: сумма < 0.3 (оба на черном)

### Дополнительные признаки пересечения

- Продолжительность состояния "оба на черном"
- Предыдущее состояние (нормальное следование)
- Отсутствие команды поворота

---

Для реализации функции проезда перекрестка в разные стороны можно воспользоваться конструкцией `switch-case`.

Конструкция `switch-case` - это способ заменить длинную цепочку `if-else if` при сравнении одного выражения с разными значениями.

`switch` берёт одно выражение (например, переменную) и последовательно сравнивает его с наборами значений в блоках `case`. Когда найдено совпадение, выполняется код начиная с подходящего `case` и до ближайшего `break` или до конца конструкции.

Общий синтаксис:

- *switch **(выражение)*** - что проверяем.
- *case **значение**:* - ветка, которая выполнится при равенстве выражения и значения.
- *break;* - прерывает выполнение `switch`, чтобы не выполнялись следующие `case`.
- *default:* - необязательная ветка "по умолчанию", если ни один `case` не подошёл.

Важные особенности:

- Сравнение обычно строгое: обычное сравнение равенства.
- Если забыть `break`, то после совпавшего `case` начнут выполняться все последующие `case`, пока не встретится `break` или конец `switch`.

```c

/*
Коды операций:
    0 - движение прямо через перекрёсток
    1 - поворот налево
    2 - поворот направо
    3 - разворот на 180 градусов
    4 - остановка
*/

void crossroad(int dir){
    switch(dir){
        case 0:
            // Код для движения прямо через перекрёсток
            ...
            break;

        case 1:
            // Код для поворота налево на перекрестке
            ...
            break;

        case 2:
            // Код для поворота направо на перекрестке
            ...
            break;

        case 3:
            // Код для разворота назад на перекрестке
            ...
            break;

        case 4:
            // Код для остановки на перекрестке
            ...
            break;

        default:
            // Код для любого другого действия
            ...
            break;
    }
}
```
