# Лабораторная №8. Пропорциональное управление

## Основы теории управления

**Пропорциональный регулятор (P-регулятор)** - это система управления, где управляющее
воздействие пропорционально отклонению от заданного значения.

### Математическая модель:

```text
u(t) = Kp × e(t)
```

Где:

- u(t) - управляющее воздействие (мощность моторов)
- Kp - коэффициент пропорциональности
- e(t) - ошибка (отклонение от линии)

### Принцип работы следования по линии

Два датчика цвета устанавливаются на робота таким образом, чтобы черная линия толщиной 2 см проходила между ними:

```text
[Левый датчик]  <-->  [Черная линия]  <-->  [Правый датчик]
```

1. Датчики измеряют отклонение от центра линии
2. Вычисляется ошибка позиционирования
3. Ошибка умножается на коэффициент усиления
4. Результат используется для коррекции скоростей моторов

Показания датчиков в разных ситуациях:
- **Линия по центру:** левый ~ 50, правый ~ 50
- **Робот левее линии:** левый ~ 80, правый ~ 20
- **Робот правее линии:** левый ~ 20, правый ~ 80
- **Оба на белом:** левый ~ 85, правый ~ 85
- **Оба на черном:** левый ~ 15, правый ~ 15

Коэффициент Kp влияет на поведение системы:

- **Kp слишком мал** - робот реагирует медленно, может сойти с линии на поворотах
- **Kp слишком велик** - робот "дергается", движение нестабильно
- **Оптимальный Kp** - плавное следование по линии с быстрой реакцией

## Нормализация данных датчиков

### Зачем нужна нормализация:

- Разные датчики дают разные диапазоны значений
- Упрощение настройки коэффициентов регулятора
- Универсальность алгоритма

### Формула нормализации:

```text
normalized = (rawValue - minValue) / (maxValue - minValue);
```

### Результат:

Значения от 0.0 до 1.0, где:

- 0.0 - минимальное значение (черная поверхность)
- 1.0 - максимальное значение (белая поверхность)

### Задача 8.3

Создайте базовый P-регулятор для следования по линии:
- Начните с Kp = 20
- Протестируйте на прямых участках
- Протестируйте на разных поворотах участках
- Постепенно увеличивайте скорость движения

#### Пример

```c
task main() {
    // Константы калибровки (заполнить из задачи 8.1)
    int leftMin = ??, leftMax = ??;
    int rightMin = ??, rightMax = ??;

    // Параметры регулятора
    int baseSpeed = 30; // базовая скорость движения
    float Kp = 20.0;    // коэффициент пропорциональности

    while(true) {
        // Чтение и нормализация датчиков
        float leftNorm = normalizeLight(getColorReflected(S1), leftMin, leftMax);
        float rightNorm = normalizeLight(getColorReflected(S4), rightMin, rightMax);

        // Вычисление ошибки
        float error = leftNorm - rightNorm;

        // Вычисление коррекции
        float correction = error * Kp;

        // Применение коррекции к моторам
        int leftSpeed = baseSpeed + correction;
        int rightSpeed = baseSpeed - correction;

        setMotorSpeed(motorD, leftSpeed); // левый мотор
        setMotorSpeed(motorA, rightSpeed); // правый мотор
        delay(50); // частота обновления 20 Гц
    }
}
```

#### Настройка параметров:

1. Если робот слабо реагирует на линию - увеличьте Kp
2. Если робот колеблется слишком сильно - уменьшите Kp
3. Если робот медленно движется - увеличьте baseSpeed

### Задача 8.4*

Создайте продвинутый регулятор и улучшите качество следования по линии.

#### Проблемы базового регулятора:

- Линейная зависимость может быть слишком резкой
- Нет ограничения максимальной коррекции
- Фиксированная скорость не оптимальна

#### Возможные усовершенствования:

1. Нелинейная характеристика:

```c
float nonlinearCorrection(float error) {
    // Кубическая зависимость для плавности
    return error * error * error * Kp;
}
```

2. Ограничение коррекции:

```c
float limitCorrection(float correction, float maxCorrection) {
    if(correction > maxCorrection) return maxCorrection;
    if(correction < -maxCorrection) return -maxCorrection;
    return correction;
}
```

3. Адаптивная скорость:

```c
int adaptiveSpeed(float error) {
    float absError = fabs(error);
    if(absError < 0.1) return 50; // прямая линия - быстро
    if(absError < 0.5) return 30; // небольшой поворот - средне
    return 15;                    // резкий поворот - медленно
}
```

##### Пример

```c
task main() {
    while(true) {
        // Чтение датчиков
        float leftNorm = normalizeLight(getColorReflected(S1), leftMin, leftMax);
        float rightNorm = normalizeLight(getColorReflected(S4), rightMin, rightMax);

        // Вычисление ошибки
        float error = leftNorm - rightNorm;

        // Адаптивная скорость
        int speed = adaptiveSpeed(error);

        // Нелинейная коррекция с ограничением
        float correction = limitCorrection(nonlinearCorrection(error), speed * 0.8);

        // Применение к моторам
        setMotorSpeed(motorD, speed + correction);
        setMotorSpeed(motorA, speed - correction);
        delay(50);
    }
}
```
